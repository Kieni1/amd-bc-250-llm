# Model-run records

Create one small Markdown record for a **consequential** run/campaign: promotion,
retirement, a surprising resource failure, a changed evaluator conclusion, or evidence
that future work is likely to repeat. Routine exploratory noise does not need a file.

Suggested filename: `YYYY-MM-DD-role-short-model.md`.

```text
ID: TASK-MODEL-YYYYMMDD-NN
Status: ACTIVE | PROMOTED | REJECTED | INCONCLUSIVE | SUPERSEDED
Package: 0.11.1-0.x
Exact model: ...
Role: ...
Exact settings: ...
Tests actually run: ...
Tests not run: ...

Observed facts:
- ...

Resource/service results:
- ...

Interpretation:
- ...

Decision:
- PROMOTE | REJECT | RETEST | NO CHANGE

Retest only if:
- ...

Evidence tarball: ...
Restoration status: ...
Credential-scan status: ...
Caveats: ...
```

Never invent an evidence filename for an older result. For a backfilled run
whose raw bundle is unavailable, say that explicitly and point to the source document
that preserves the summarized observation. Never commit credentials, private backup
contents, private SSH keys or GGUF weights here.
